## Defects found during clean-room validation

The first clean-room test run exposed:

1. a startup race in which concurrent workers negotiated WAL mode before a busy
   handler was installed; and
2. two cadence tests that attempted to mutate the identity-bound
   `initiated_at` field after the immutability trigger was active.

The later Antigravity v4 draft was also tested before import and failed 27 of
31 tests because its foundation assertion could not be satisfied. The adapted
v4 implementation uses the repository's actual schema, recreates all dependent
triggers, preserves legacy payload bytes, and adds explicit v2-to-v4,
v3-to-v4, missing-result, and result-tamper assays.

The proposal installs the SQLite busy handler before WAL negotiation and gives
the cadence sweep an injectable observation time. Tests now advance the clock
without mutating persisted obligation identity.
