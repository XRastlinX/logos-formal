# Proposals

This directory contains reviewable artifacts that are not part of the
repository's active canon or production runtime.

Unless a proposal says otherwise, every artifact here has:

- lifecycle: `PROPOSED`
- promotion evidence: `MISSING`
- authority effect: `NONE`
- deployment effect: `NOT_PERFORMED`

Placement in this directory records a development proposal. It does not adopt,
permit, deploy, or establish the artifact.
