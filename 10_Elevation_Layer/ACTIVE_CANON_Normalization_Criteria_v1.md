Stage 8 ($\sigma_8$) represents the **Normalization Gate**. It provides a deterministic, machine-checkable assertion that a cord has reached structural maturity and stability, rendering it eligible for long-term retention, cross-boundary export, or downstream structural use.

## The Six Invariants of Normalization

A Cord $C = (i, r, f)$ along with its capability geometry $cy(x) = \{A, I, E\}$ is considered **normalized** if and only if all six of the following criteria are strictly satisfied:

1. **Invariant Integrity**
   $f = i + r$. (Exception: if the object is explicitly locked under the $010$ child state, $f$ remains $\bot$). No residual drift or unauthorized framing may be present.

2. **Capability Stability**
   The capability triple $\{A, I, E\}$ remains mathematically constant under the current Context. There can be no spontaneous elevation or collapse upon re-evaluation.

3. **Dual-Projection Consistency**
   The dual projection $\Pi(C, x) = (q(C), cy(x))$ returns a structurally non-conflicting pair. Q-content (the cord) explicitly does not attempt to set or alter Cy-capabilities (the governance geometry). The epistemic boundary must remain perfectly intact.

4. **Null-Prime Respect**
   If the originating cord stems from $gap = 1$, the object must remain strictly the zero-weight identity $(i = \emptyset, r = \emptyset, f = \bot)$ and is permanently forbidden from promotion.

5. **No Pending Transition**
   The cord is not mid-flight (e.g., carrying a flux operator $\Delta$) in any of the stages $\sigma_1 \dots \sigma_7$. All prior developmental stages must have completed successfully or been explicitly aborted/collapsed.

6. **Reproducibility**
   Re-executing the dual projection and the invariant check on identical inputs must yield mathematically identical results, guaranteeing deterministic settlement.
